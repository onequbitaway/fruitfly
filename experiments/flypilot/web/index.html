What controls the drone

The street camera returns a rendered character mask and depth. These are game sensors. A chosen input map sends the measurements to the fly model. A trained output map reads calculated cell rates. A flight controller keeps the drone level.

The wiring stays fixed. Training changes only the output map. The fly model does not recognize a person.

Read the view

Hz means spikes per second. Each point uses a recorded cell position. The plot shows a fixed sample of positions. All cells still run. Cell brightness uses the exact saved rate.

Simple uses smell cells as a visual proxy. Its weights are trained separately.

Limits and controls

The walking character is fictional. Its walk and contact response are programmed. A body contact ends the encounter. The scene uses geometric contact and boundary checks. Native drone contact is disabled.

Reset starts the same seed. Mode starts a new run. Pause stops model time. The model may run slower than real time.

Studio mode follows a NASA sample portrait with an image matcher. Street mode uses an animated 3D character. No real camera, real drone, account, or analytics is used.
