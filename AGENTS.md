# Project rules

- Build a small Mac desktop pet. Keep the app easy to download and run.
- Use Swift and Apple frameworks. Add a dependency only when it solves a clear problem.
- Follow ASD-STE100 writing rules in user text: short sentences, active voice, and one instruction per sentence.
- Prefer common words. Define necessary technical terms. Do not claim certified STE compliance.
- Keep a clear boundary between measured brain data and programmed behavior.
- Never label programmed movement as learned behavior.
- Keep normal mouse input available to other apps.
- Do not start at login unless the user enables that feature.
- Do not collect analytics or require an account.
- Keep raw brain data and build output out of Git.
- Preserve the source and license of any included data.
- Run meaningful tests and the app build before a release.
- Document required macOS permissions and the limits of an unsigned download.
