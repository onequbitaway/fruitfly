Watch the smell circuit respond when you drop food.

- A new brain window shows all 3,745 included cells.
- Each dot reads its cell's current model value.
- A chart shows food input and circuit output over ten seconds.
- Drop food and pause from the brain window.
- The GitHub page includes a recorded run and every cell value from that run.

The connections come from the MaleCNS map. Activity values come from the app's simulation.
Dot positions are a diagram, not anatomy. The fly does not learn.
Food search and other pet behavior also use programmed rules.

Download the ZIP file. Extract it, then move Fruitfly to Applications.
The app supports macOS 14 or later on Apple Silicon and Intel Macs.
No account or separate data download is required.

This download does not yet have Apple approval through notarization.
If macOS blocks the app, use Privacy & Security in System Settings to review the Open Anyway option.
