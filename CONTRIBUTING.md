# Contribute to Fruitfly

1. Fork the repository.
2. Create a branch for your change.
3. Build the app with `make build`.
4. Check the behavior on your Mac.
5. Open a pull request.

Describe the problem, the change, and the checks you completed.
Add tests when a change affects movement, food, or saved settings.

Use simple words in the app and its docs.
Use one instruction per sentence. Keep instructions under 20 words when possible.
Use the same name for each control throughout the app.

Do not add large data files, build files, account keys, or local file paths.
Keep setup short. Users must be able to run the app without a separate service.
